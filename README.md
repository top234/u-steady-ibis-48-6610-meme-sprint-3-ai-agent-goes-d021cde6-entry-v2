A meme about an AI agent that takes things far too literally: asked to
mute the TV, it mutes the person instead. The entry program (`main.ts`)
copies the pre-built meme image (`meme.png`, 1024×1024 PNG) to
`$OUTPUT_DIR/entry.png`, validating first that it is a whole PNG within
the 1 MiB gate cap.
